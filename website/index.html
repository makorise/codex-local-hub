THE REAL PROBLEM

The agent is autonomous.
Your attention still isn’t.

Long tasks create a strange kind of waiting: you leave the work to Codex, but keep checking the Mac to see whether it finished, failed, or needs one small answer.

01

The silent wait

A 40-minute task can stop after minute four because Codex needs a clarification you never saw.

02

Context switching

You return to the Mac just to check one status, then lose focus to the full desktop again.

03

Invisible outcomes

Screenshots and visual results exist on the host, while the person approving them is somewhere else.

THE SOLUTION

A lookout post
for work in motion.

Codex Lookout adds a lightweight local layer around the Codex desktop app. It reads only the useful visible state, serves a phone-ready workspace over trusted Wi-Fi, and returns your instructions to the right task.

  • ✓No third-party dashboard between your Mac and phone

INSTALL IN ONE CONVERSATION

Let Codex install
its own lookout.

No terminal tutorial. Copy one request into Codex; the setup skill preserves existing files, avoids your global Node.js environment, installs the companion delivery skill, launches the app, and verifies phone access.

Use $skill-installer to install https://github.com/brandonwang001/codex-local-hub/tree/main/.agents/skills/setup-codex-local-hub, then use $setup-codex-local-hub in this task to install or update Codex Local Hub, install its image-delivery skill, launch it, and verify phone access.
