# Contributing to Codex Local Hub

Thank you for helping improve Codex Local Hub.

1. Search existing issues before opening a new one.
2. Keep changes focused and explain the user problem they solve.
3. Run `npm test` and `npm run test:coverage` before submitting a pull request.
4. Preserve local-first privacy: do not add telemetry, upload conversations, or expose hidden reasoning.
5. Add or update tests for every behavior change.
6. Keep English and Simplified Chinese user-facing copy aligned.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
