# Security policy

Only the latest released version is supported with security fixes.

Codex Local Hub is designed for trusted local networks. Do not expose its HTTP port directly to the public internet. Remote access must use a TLS-secured relay or VPN with device authentication.

New browsers pair through the QR code shown by the macOS app. Treat pairing links and session cookies as secrets. If you suspect exposure, quit the app, remove the stored session secret, and restart to generate a new one.

Please report vulnerabilities privately to the repository maintainer. Include affected versions, reproduction steps, impact, and any proposed mitigation. Do not include real conversation data or credentials.
